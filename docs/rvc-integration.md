# Juliette TTS → RVC integration

## Scope

RVC is an optional post-processing stage for audio generated by TTS engines.
It never captures or converts microphone audio. Loquendo remains usable when
RVC is disabled. Model download and inference run outside Wispbyte.

## Flow

1. The selected TTS provider generates a WAV.
2. Juliette selects an enabled model from `rvc_models.json`.
3. The adapter sends the WAV, model ID, and the catalog-controlled Google
   Drive download URL to the remote HTTPS inference service.
4. The service downloads the ZIP once, validates and extracts the RVC v2
   `.pth` and optional `.index`, caches them, then performs inference.
5. The service returns a WAV in JSON `audio_base64`.

## Request contract

```json
{
  "model": "kasane-teto-synthv-rvc-v2",
  "input_format": "wav",
  "audio_base64": "<base64 WAV bytes>",
  "model_download_url": "https://drive.google.com/uc?export=download&id=...",
  "model_archive_format": "zip"
}
```

Response:

```json
{"audio_base64": "<base64 converted WAV bytes>"}
```

The service must allowlist Google Drive HTTPS URLs, impose download size and
time limits, reject path traversal and unexpected archive contents, validate
the extracted RVC checkpoint, and cache by model ID. It must not accept an
arbitrary URL from the caller. Do not enable a model until the service confirms
the model is installed and inference has passed a test.

## Kasane Teto model

The catalog includes Kasane Teto (SynthV), Japanese, RVC v2, 500 epochs,
hosted as a 63 MB Google Drive ZIP by Ezarot. The catalog entry is disabled
until the remote inference service downloads and verifies the weights.

## Resource boundary

Do not run RVC inference in the Wispbyte bot process. It has insufficient
resources for a dependable RVC stack. Configure `JULIETTE_RVC_URL` only
after deploying a trusted HTTPS service that implements this contract.
